# 電腦小勇士 — 老師使用說明

給國小中年級的電腦基本知識闖關遊戲。**純網頁、不用安裝、不連網**，所有圖片都是程式畫的，離線也能用。
做法參考「注音打字小勇士」，老師密碼也和它相同。

## 一、怎麼開

1. 把整個 `computer-quiz` 資料夾複製到學校共用資料夾或隨身碟（`index.html`、`core.js`、`art.js`、`questions.js`、`app.js`、`style.css` 要放在一起）。
2. 學生電腦**用 Edge 或 Chrome** 對 `index.html` 按兩下。

## 二、五個關卡

| 關卡 | 內容 | 題型 |
|---|---|---|
| 1 鍵盤小幫手 | Shift 切換中英、Enter、Backspace、空白鍵、↑；大寫（Shift+字母、Caps Lock）；中文標點 Ctrl+, ，／Ctrl+. 。／Ctrl+' 、／Ctrl+Shift+/ ？／Ctrl+Shift+1 ！／Ctrl+Shift+; ：；符號小鍵盤 Ctrl+Alt+,；Ctrl+C／V／Z／S | 在螢幕鍵盤上點出答案（也可以直接按實體鍵盤） |
| 2 滑鼠大師 | 左鍵、右鍵、滾輪、點一下 vs 連點兩下、拖曳、游標形狀 | 在滑鼠圖上點、選擇題、動手操作 |
| 3 檔案與資料夾 | 打開資料夾、新增資料夾、重新命名、刪除、資源回收筒、檔名 | 動手操作、在檔案總管圖上點 |
| 4 桌面與視窗 | 開始鈕、工作列、輸入法「中／英」圖示、時鐘、最小化／最大化／關閉 | 在桌面圖、視窗圖上點 |
| 5 綜合挑戰 | 1～4 關混合，多 2 題，一定計時 | 全部 |

### 四種題型

- **點鍵盤**：組合鍵（例如 Ctrl + C、Ctrl + Shift + /）要依序點每個鍵。Windows 鍵只接受用滑鼠點（實體按下去會被 Windows 攔走）。
- ⚠ 標點符號與符號小鍵盤的快捷鍵是依微軟注音常見教學整理，**請先在學校電腦的記事本（中文模式）實按一次確認**，版本不同可能略有差異。
- **點圖片**：答錯時，正確位置會出現**閃爍的黃框**，點錯的地方是紅色虛線框。
- **選擇題**：選項順序每次會打亂。
- **動手做做看**：在假的桌面／資料夾上真的操作——連點兩下打開、按右鍵選「新增 → 資料夾」、拖曳到資源回收筒、用滾輪找寶藏。
  做錯會跳提示，可以繼續做；**有失誤的話做完也不算星星**。只點一下（選取）不算失誤，會提醒「要連點兩下」。

每題答完都會顯示一句白話解說；結算畫面會列出答錯的題目再複習一次。
星星：正確率 90% 以上 3 顆、70% 以上 2 顆、其他 1 顆。

## 三、老師模式（首頁右上角 ⚙，密碼同注音打字小勇士）

- 開放哪幾關、每關題數（預設 8 題）、是否每關都計時、音效、結算時是否顯示「輸入姓名」。
- 成績**只存在那台電腦的瀏覽器裡，不會上傳**。可查看、**匯出 CSV**（Excel 可直接開）、清空。CSV 會多一欄「答錯的題目」，方便看全班哪裡不熟。

## 四、修改題目（questions.js）

用記事本開 `questions.js`，**存檔時編碼選 UTF-8**。檔案最上面有每種題型的寫法說明，照著現有的題目複製一份再改字最快。例如：

```js
{ level: 1, type: 'key', q: '要切換中英文，要按哪個鍵？', keys: [['Shift']],
  explain: '按一下 Shift 就能切換中文和英文。' },
```

- 題目要附圖，可以用 `art: 'mouse'`（滑鼠）、`'desktop'`（桌面）、`'window'`（記事本視窗）、`'explorer'`（檔案總管）。
  圖上每個可以點的位置名稱寫在 `art.js` 最上面。
- **示範動畫**：每題都可以加 `demo: [...]`，題目上方會出現一個自動輪播的迷你記事本（像 GIF），讓看不懂題目的孩子「看效果」。
  每一格寫一個 `{ t: '文字' }`，`|` 是游標、`\n` 是換行，`key: ['？']` 會在右邊顯示按鍵動畫。
  **答案鍵請寫成「？」**，不要直接把答案演出來。完整寫法在 `demo.js` 最上面。例：
  ```js
  demo: [{ t: '今天天氣很好|' }, { t: '今天天氣很好|', key: ['？'] }, { t: '今天天氣很好\n|' }],
  ```
- 改完後請開遊戲把新題目玩一次，確定沒打錯字（少一個逗號整個遊戲會開不起來）。

## 五、上課前 3 分鐘檢核

1. 開第 1 關：按實體鍵盤的 Shift → 答對。
2. 開第 3 關：遇到「打開資料夾」題，先點一下 → 出現「要連點兩下」提示；連點兩下 → 答對。
3. 結算畫面「記錄成績」→ 老師模式看得到這筆記錄。

## 六、更新後學生看到舊版

`index.html` 每個檔案後面有 `?v=20261012`。改過程式或題庫後，把它們全部改成當天日期，或請學生按 **Ctrl + F5**。
